# iptvnetherland.com – static site (GitHub Pages)

Static copy of the former WordPress site. Orders go through WhatsApp (see the buttons on the homepage).
Generated by `scripts/build_static.py` in the private SEO repo; a rebuild overwrites generated pages.

- `CNAME` = custom domain, `.nojekyll` = serve files as-is, `sitemap.xml` / `robots.txt` for search engines.
- Pages that no longer exist (cart, checkout, shop, products, duplicate posts) are small redirect pages.
